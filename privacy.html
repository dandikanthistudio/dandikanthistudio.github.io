Privacy Policy: Dandi Kanthi Studio app

Last updated: 2 November 2026

Who uses this app

This app is a private tool used only by the owner of the Dandi Kanthi Studio YouTube channel. It is not offered to the public.

What data it accesses

With the owner's permission, the app uses the YouTube Data API and YouTube Analytics API to upload videos, set titles, descriptions, thumbnails and playlists, read the channel's own video statistics, and read and reply to comments on the channel's own videos.

How data is stored

The sign-in token and channel statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions.
